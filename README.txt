СТУДИЯ РАСПИСАНИЙ 2.5
=====================

Настольный редактор расписания с несколькими залами, своим названием студии,
цветами и размерами экспорта. Работает локально, без регистрации.

ЗАПУСК НА WINDOWS
1. Установите Python 3.10 или новее с python.org (рекомендуется 3.12).
   В установщике включите Add python.exe to PATH.
2. Распакуйте весь ZIP в новую папку, включая assets и colors.py.
3. Запустите launch.bat из распакованной папки, не прямо внутри ZIP.
   При первом запуске нужен интернет для установки зависимостей.
   Существующая пользовательская папка данных продолжит использоваться.

Скрипты launch.bat и build.bat записаны в ASCII с окончаниями CRLF:
это предотвращает ошибки командной строки Windows с обрывками команд.

ЧТО НОВОГО В 2.5
- Вкладка «Оформление»: регулировка прозрачности общей заливки над картинкой
  и отдельная регулировка прозрачности подложек дней, от 0 до 100%.
- Чем выше процент, тем лучше видна фоновая картинка. При 100% общая заливка
  не приглушает изображение, а подложки дней полностью скрыты.
- Карточки тренировок, заголовки дней и время остаются непрозрачными и читаемыми.
- Изменения видны в предпросмотре, применяются ко всем форматам экспорта,
  сохраняются в проекте и поддерживают отмену/повтор действий.
- Для заметного фона попробуйте 85% для заливки и 55% для подложек дней.
  Ползунок заливки влияет на картинку, выбранную как фон.
- Старые проекты открываются с прежним видом: 8% и 0% соответственно.
  Чтобы увидеть фон, увеличьте значения во вкладке «Оформление».
  Пример сравнения: examples/transparency.

ИЗМЕНЕНИЯ ВЕРСИИ 2.4
- Логотип крупно размещается слева от заголовка как часть общей шапки.
  Прозрачные поля PNG автоматически убираются при размещении; исходник не меняется.
  Пропорции сохраняются, маленький логотип увеличивается до выделенного места.
- Для названий тренировок используется Manrope Medium, для заголовков — SemiBold.
  Шрифты с кириллицей включены в программу, устанавливать их в Windows не нужно.
- Одно- и многострочные названия центрируются по видимым границам букв.
  Учтены верхние и нижние элементы букв, а не только номинальная высота строки.

ВОЗМОЖНОСТИ ВЕРСИИ 2.3
- Исправлены нечитаемые области: светлая палитра задана явно для меню,
  списков, таблицы, настроек и диалогов независимо от тёмной темы Windows.
  Стиль экспортируемых картинок можно выбирать отдельно.
- Вкладка «Студия и залы»: название студии для заголовка окна и картинок;
  добавление залов, переименование, смена цвета, удаление с подтверждением.
- Залы имеют постоянные идентификаторы. Переименование и смена цвета
  не изменяют назначения тренировок. Цвет текста на картинках автоматически
  выбирается чёрным или белым для контраста с выбранным цветом зала.
- Вкладка «Форматы»: свои ширина, высота в пикселях и DPI.
  Свои форматы можно переименовать, изменить или удалить.
- Перед экспортом отметьте нужные форматы. Сохраняются только отмеченные;
  выбор запоминается. Свои размеры доступны также в предпросмотре.
- Данные версий 1.x/2.x открываются без потери расписания.

КАК РАБОТАТЬ
1. «Тренировки»: добавьте названия, используйте поиск и переименование.
   Переименование обновит занятия во всех залах, включая скрытые дни.
2. «Студия и залы»: настройте название и нужные залы. Поддерживается до 12 залов.
   Порядок залов в списке определяет порядок строк в редакторе и картинках.
3. «Расписание»: выберите дни и добавьте время. Каждая ячейка редактора
   содержит список для каждого зала. Пустой пункт снимает назначение.
   Скрытие дня не удаляет его занятия; копирование дня заменяет назначения.
4. «Оформление»: заголовок, подзаголовок, период, подпись, логотип и фон.
   Название студии меняется отдельно от подзаголовка: оба текста независимы.
5. «Форматы»: добавьте свои размеры при необходимости.
6. Выберите формат в предпросмотре. Двойной щелчок или «Крупный просмотр»
   открывает картинку с масштабированием и прокруткой.
7. «Экспорт картинок»: отметьте нужные форматы и выберите PNG либо JPEG.

Сохранение автоматическое примерно через секунду после правки, Ctrl+S — сразу.
Ctrl+Z — отмена, Ctrl+Shift+Z — повтор. История: 100 действий в текущем запуске.
Перед удалением зала программа спросит подтверждение: его занятия будут удалены
во всех днях, остальные залы сохранятся. Удаление можно отменить.
Чтобы удалить время, выберите строку по заголовку слева и нажмите «Удалить время».

ЭКСПОРТ
Стандартные форматы:
- A4 для печати: 3508×2480, альбомная ориентация, 300 DPI.
- Сторис: 1080×1920.
- Пост ВК: 1080×1350.
Можно добавить до 20 форматов всего. Свои размеры: 320–8000 пикселей по стороне,
до 40 мегапикселей на картинку; DPI — 72–600. DPI задаёт масштаб печати,
а ширина и высота определяют число пикселей.

В любом формате вся неделя остаётся на одной сетке. Время указывается один раз
слева. Если в ячейке одно занятие, карточка занимает всю её высоту. Если занятий
несколько, они делят ячейку поровну в порядке залов. Место под пустые залы
не резервируется. Названия переносятся без многоточия.
При слишком плотном расписании программа предложит сократить названия,
выбрать больше места или уменьшить число временных строк. Дополнительные страницы
не создаются. Невыбранные форматы не проверяются и не экспортируются.

Перед записью проверяются все выбранные макеты. Выгрузки называются
bogini_a4.png, bogini_story.png, bogini_vk_post.png; свои — schedule_custom_....png.
Для JPEG используется расширение .jpg. Одноимённые файлы заменяются,
остальные файлы не удаляются: выбирайте отдельную папку для каждой недели.
Шрифты входят в комплект; лицензии находятся в assets/fonts/Manrope-OFL.txt
и assets/fonts/LICENSE.txt. Демо логотипа и шапки: examples/typography.

ДАННЫЕ И СОВМЕСТИМОСТЬ
«Проект → Сохранить копию проекта» сохраняет отдельный JSON.
«Открыть проект» заменяет текущее расписание после подтверждения; доступна отмена.
Пути к фонам и логотипу хранятся в JSON, сами картинки в проект не включаются.
При переносе на другой компьютер скопируйте картинки и выберите их заново.

«Проект → Открыть папку данных» показывает пользовательскую папку приложения.
Её путь и внутреннее имя Bogini/BoginiSchedule сохраняются при переименовании
студии, чтобы старые данные не потерялись.
project-v2.json — текущий проект; project-v2.backup.json — предыдущая запись.
Имя файла оставлено для совместимости, внутри сохраняется схема версии 3
с залами и форматами. Читать её следует в версии программы 2.3 или новее;
для сохранения настроек прозрачности используйте 2.5 или новее.
Запись атомарная; при повреждении основного файла открывается резервная копия
с предупреждением. Перед крупными изменениями сохраняйте отдельный JSON.

Старые trainings.json, settings.json и schedule.json автоматически открываются,
если нового проекта ещё нет, из пользовательской папки или data рядом с программой.
Также есть «Импорт из старой программы». Исходные старые файлы не изменяются.
Большой зал переносится как зелёный, малый — как фиолетовый; затем их можно менять.

СБОРКА EXE НА WINDOWS
Запустите build.bat. Результат: dist\BoginiSchedule.exe.
В готовый EXE входят Python, зависимости и шрифты. Windows EXE собирается на Windows.
Старый пустой EXE из репозитория не используйте.
В .github/workflows/windows.yml есть сборка через GitHub Actions.

РАЗРАБОТКА
  python -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements.txt
  .venv\Scripts\python.exe main.py
  .venv\Scripts\python.exe -m unittest discover -s tests -v
На Linux/macOS используйте .venv/bin/python.
Тесты без дисплея: QT_QPA_PLATFORM=offscreen.
Примеры картинок без изменения вашего проекта:
  python main.py --export-demo examples

main.py — интерфейс; model.py — хранение и перенос данных; rendering.py — экспорт;
colors.py — контраст текста; demo.py — пример расписания.
